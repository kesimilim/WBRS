# Встречи: локальная проверка по фото 1, 4 и 5

Проверена текущая исходная версия поверх `cd49042`, Flutter 3.32.5. Это widget/render доказательство; APK, live backend и миграция данных этим отчётом не подтверждаются.

## Что изменено

- `lib/presentation/screens/list_of_meets/meetings.dart`: мануал содержит четыре короткие карточки (индивидуальная, коллективная, место и время, участники), номера/иконки/переходы, логотип и фразу сверху, компактный существующий footer и доступную кнопку «Понятно». Подробные прежние пояснения сохранены по нажатию на карточки. Карточки занимают левые 2/3; увеличение текста сохраняет прокрутку.
- В обеих шапках под фразой есть маленькое outline-сердечко. В списке встреч «Создать» сохраняет alpha 64/255, то есть прежние 75% прозрачности. Геофильтры стоят горизонтально, имеют компактную высоту 30 px и inline label/value; длинное выбранное значение сокращается только визуально, полное значение остаётся в tooltip, semantics и данных выбора. Карточка занимает всю ширину, описание и факты находятся справа от фотографии. Дата `Timestamp` отображается как дата, без служебного представления объекта.
- `lib/presentation/screens/meet_chat_screen/chat_page.dart`: уведомления и участники доступны сверху; сведения о встрече занимают только левые 2/3. Сообщения располагаются перед композером, композер занимает всю ширину; send — круглая персиковая кнопка, двойная рамка поля убрана. На коротком landscape с клавиатурой шапка становится компактной, приоритет получает композер. Insets клавиатуры берутся над Scaffold, поскольку MediaQuery внутри body уже очищен Scaffold.
- В `lib/app/widgets/message_tile.dart` / `lib/shared/translatable_text.dart` добавлен необязательный `compactMeeting=false`. ChatPage включает его только для простого текста: аватар 32 px, имя с исходным регистром над пузырём, текст 13 px, отступы 6/8, прозрачный коричневый фон, время внутри, компактное действие перевода под фоном пузыря. Входящие ограничены левыми 2/3, исходящие выровнены вправо. Gift/shared/nontext/reply используют прежний полный tile с фоном и полной цитатой. Другие callers сохраняют прежний стиль по умолчанию. Provider/cache/session logic и обработчики reply/edit/delete/copy не менялись.
- В 23 bundled catalogs добавлено четыре подписи, включая «Ближе к настоящему» для Settings. Облачные переводы не использовались.

## Что уже совпадало

Существующие фотографии, горизонтальная компоновка геофильтров, полноширинные карточки и действие перевода под текстом сообщений уже были в репозитории. Фотографии не генерировались и не редактировались. Для главной страницы выбран существующий `family_front.png`, для мануала сохранён `family_right.png`, для чата выбран указанный root `assets/family_main.jpg` (светлая рубашка мужчины и две дочери). Общие assets не заменялись. Мануал сохраняет back-arrow: это фактический push-route, собственного drawer у него нет.

В meeting composer нет существующего attachment/picker handler; `ChatSubmissionService` сохраняет текст/shared-content. Disabled-скрепка другого native chat не является рабочей media-operation. Новое действие вложения не добавлялось; оно остаётся отдельной функциональностью за рамками этих UI-исправлений.
