# Спецификация API: Синхронизация обоев чата на сервере

Этот документ описывает опциональный серверный метод для сохранения индивидуального фона (обоев) личного чата в базе данных Timeweb, обеспечивая синхронизацию между устройствами пользователя.

---

## 1. Действие обновления обоев чата (`set-chat-wallpaper` / `update_chat_wallpaper`)

### Назначение:
Позволяет сохранить выбор фонового изображения для конкретного чата на сервере. Если бэкенд еще не поддерживает этот метод, клиент автоматически использует локальное хранилище (`SharedPreferences`).

### Требуемый формат полезной нагрузки (Payload):
```json
{
  "kind": "set-chat-wallpaper",
  "chatId": "tw-chat-...",
  "wallpaperAsset": "assets/wallpaper/8.jpg"
}
```

### Требования к серверу:
- Проверять, что текущий пользователь является участником указанного чата `chatId`.
- Сохранять значение `wallpaperAsset` в таблице/коллекции настроек чата или участников (`chat_participants` / `chat_settings`).
- Возвращать подтверждение успеха (`status: 200` или подтвержденный state).
